# 🍱 Lunch Lab (오늘의 점심 연구소)

모바일 웹 퍼스트(Mobile-Web First) 환경에 최적화된 **화려하고 감각적인 점심 메뉴 관리 및 실시간 런치톡 웹 애플리케이션**입니다.

---

## 🌟 주요 특징 및 구현 기능

### 1. 📱 화려한 모바일 퍼스트 디자인 & 반응형 UI
- **글래스모피즘 & 선셋 오렌지 그라디언트**: 식욕을 돋우는 네온 코랄, 앰버 골드, 블러 백드롭의 세련된 비주얼
- **스마트폰 뷰 & 데스크탑 듀얼 뷰 지원**:
  - 모바일 기기(아이폰/갤럭시 등)에서는 **100% 네이티브 앱 느낌**의 풀스크린 UX 제공
  - PC 브라우저에서는 **아이폰 16 Pro 스타일 모바일 프레임** 및 **스플릿 듀얼 뷰(좌측: 메뉴/룰렛 + 우측: 실시간 대화창)** 전환 버튼 탑재
- **화려한 마이크로 인터랙션**:
  - 하트(❤️) 투표 시 플로팅 파티클 애니메이션
  - 룰렛 당첨 및 메뉴 등록 시 축하 **콘페티(폭죽) 파티클 효과**
  - 다크 모드(🌙) / 라이트 모드(☀️) 즉시 전환

---

### 2. 🍲 점심 메뉴 데이터베이스 관리 & 필터링
- **카테고리별 체계적 분류**:
  - 🍚 한식 / 🥟 중식 / 🍝 양식 / 🍢 분식 / 🍜 면종류 / 🍣 일식 및 아시안 / 🍔 기타
- **실시간 검색 & 다각도 정렬**:
  - 메뉴명, 추천 식당, 해시태그(#해장, #가성비, #불맛), 설명으로 즉시 검색
  - 🔥 인기순(좋아요 많은 순), 🕒 최신순, 💰 가격 낮은순/높은순 정렬
- **상세 정보 및 인터랙션**:
  - 메뉴명, 카테고리 뱃지, 가격(원), 추천 식당/위치, 한줄평, 해시태그
  - **좋아요(❤️) 실시간 투표**: 클릭 즉시 DB 반영 및 모든 접속자에게 실시간 반영
  - **대화창에 추천(💬)**: 원클릭으로 런치톡 대화방에 추천 메시지 전송
  - **메뉴 직접 등록(➕)**: 하단 바텀시트 모달로 누구나 손쉽게 새로운 점심 메뉴 추가
  - 영구 저장 DB (`data/db.json` 파일 기반 지속성)

---

### 3. 🎲 "오늘 뭐 먹지?" 결정 룰렛
- 점심 메뉴 결정장애를 단번에 해결해주는 **인터랙티브 캔버스 룰렛**
- 특정 카테고리만 골라서 돌리기 지원 (예: '한식만', '면종류만')
- 회전 시 실시간 물리 감속 애니메이션 & 당첨 축하 팝업
- "런치톡에 자랑하기" 버튼으로 당첨 메뉴를 대화방에 1초 공유

---

### 4. 💬 로그인 필요 없는 실시간 런치톡 (대화창)
- **로그인 불필요**: 복잡한 회원가입 없이 **본인 닉네임만 입력**하면 즉시 대화 참여
- **재미있는 랜덤 닉네임 생성기(🎲)**: '배고픈 판다 🐼', '불타는 제육 🥩', '프로혼밥 버거 🍔' 등 클릭 한 번으로 자동 부여
- **실시간 웹소켓(WebSocket) 동기화**:
  - 지연 없는 실시간 말풍선 전송 (내 메시지 / 상대방 메시지 구분)
  - 퀵 이모지 툴바 (🤤, 🍱, 🍜, 🥩, 👍, 🔥, 🍕) 원클릭 전송
  - 실시간 접속자 수 표시 (🟢 N명 대화중)
  - 최근 대화 기록 자동 보존

---

## 🚀 실행 방법

### 1. 패키지 설치 (최초 1회)
```bash
cd lunch
npm install
```

### 2. 서버 실행
```bash
npm start
# 또는
node server.js
```

### 3. 접속 주소
- **PC 브라우저 접속**: [http://localhost:3000](http://localhost:3000)
- **모바일 스마트폰 접속**: 같은 Wi-Fi 망에서 스마트폰 브라우저로 터미널에 안내된 IP(`http://[내-IP]:3000`) 접속

## 📂 디렉토리 구조

```
mu/lunch/
├── package.json          # 패키지 설정 및 스크립트
├── server.js             # Express 서버, WebSocket 및 REST API, DB 엔진
├── data/
│   ├── seed.json         # 초기 추천 메뉴(20개) 및 환영 채팅 시드
│   └── db.json           # 메뉴 및 채팅 데이터 지속 저장소
└── public/
    ├── index.html        # 모바일 최적화 웹앱 메인 페이지
    ├── css/
    │   └── style.css     # 화려한 글래스모피즘, 모바일 프레임, 애니메이션 스타일
    └── js/
        ├── app.js        # 전체 탭, 메뉴 CRUD, 필터, 정렬 관리
        ├── chat.js       # 로그인 없는 실시간 닉네임 채팅 클라이언트
        ├── roulette.js   # "오늘 뭐 먹지?" 캔버스 룰렛 모듈
        └── confetti.js   # 축하 파티클/폭죽 애니메이션 엔진
```
